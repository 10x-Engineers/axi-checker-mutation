## How it works

```
 cocotb AXI manager ─m_*─► [ interposer ] ─s_*─► axi_ram (DUT)
                                 │
                                 └─ obs_* ─► checker set under test
                                          └► data scoreboard
```

The interposer puts one protocol violation (a *mutant*) on the bus the checker watches. The
real traffic is unaffected. Each run gets a verdict:

| Verdict | Meaning |
|---|---|
| **CORRECT** | the rule for the broken clause fired within the mutant's window |
| **LATE** | the wrong rule, too late, or only the data scoreboard noticed |
| **MISSED** | nothing noticed |
| **FLAGGED** | a rule fired on a legal perturbation (false positive) |
