# axi-checker-mutation

**Qualify AXI4 protocol checkers by mutation**, whether they were written by hand or
generated by an LLM, using open-source tools only.

A checker that never fires looks identical to a design that has no bugs. This repository
measures which checkers actually fire: it injects one specification-derived protocol
violation at a time onto the bus a checker watches, and grades the result.

```
 cocotb AXI manager ─m_*─► [ interposer ] ─s_*─► DUT (verilog-axi axi_ram)
                                 │
                                 └─ obs_* ─► checker set under test   ─► which rule fired, when?
                                          └► data scoreboard (downstream)
```

- **The design is trusted; the checker is on trial.** The interposer applies the mutation to
  the observed bus only. The real manager and DUT exchange unchanged data and see nothing but
  legal back-pressure, so every run's own data check still passes.
- **Every mutant cites the rule it breaks**: section, page and sentence of ARM IHI 0022
  Issue L (`catalog/clauses.toml`).
- **Kill quality, not just kill rate:**

  | Verdict | Meaning |
  |---|---|
  | CORRECT | the rule for the broken clause fired within the mutant's window |
  | LATE | the wrong rule, too late, or only the downstream data scoreboard noticed |
  | MISSED | nothing noticed |
  | FLAGGED | a rule fired on a *legal* perturbation: a false positive |

## Quick start

See [SETUP.md](SETUP.md) ([中文](SETUP.zh.md)), then:

```bash
./check_env.sh                                         # ALL PASS
python3 harness/qualify.py --checkers llm_opus -j 8    # grade one checker set
python3 harness/show.py --checkers llm_opus --mutant same-id-read-swap   # explain one run
python3 harness/matrix.py                              # compare your runs with the reference results
```

Bring your own checker, from any LLM or written by hand:

```bash
python3 tools/new_checker_set.py my_set --from path/to/axi_checker_set.sv
python3 harness/qualify.py --checkers my_set
```

The hands-on labs are in [labs/](labs/README.md).

## Contents

| Path | |
|---|---|
| `rtl/` | the DUT-independent mutation interposer (VALID drop, glitch, override, handshake delay, burst swap, and a legal stall) |
| `catalog/` | `clauses.toml` (spec rules), `mutants.toml` (violations), `legal.toml` (legal perturbations that must not fire) |
| `checkers/` | `none` (control), `pulp_axi` (open-source baseline), `llm_*` (reference sets generated blind by LLMs, with `PROVENANCE.md`), `llm_prompt/` (the generation prompt) |
| `tb/` | cocotb testbench, reference stimulus, observed-bus data scoreboard |
| `harness/` | `qualify.py`, `show.py`, `matrix.py` |
| `results/` | reference `qualify.json` for each public set in `checkers/` (Verilator 5.052); `matrix.py` uses them for any set you have not run |
| `tools/` | `new_checker_set.py`, `gen_checker.py` (any OpenAI-compatible LLM API), `spec_text.py`, `import_pulp.py`, `sva_smoke/` |

## Contributing a mutant

1. The broken rule is a **MUST** (or its direct converse) in IHI 0022, cited by section and page.
2. The mutant is shown **injected** (not `NOT_INJECTED`) on the reference stimulus.
3. At least one checker set kills it, or the entry says why none can (`checker_visible = false`).
4. The clean run and every legal perturbation stay clean.
